🚀 How to Start

1
Choose mode & provider
Simple Bot needs no API key. AI Bot needs a Gemini, OpenAI, or Claude key.
2
Enter API key & save
Click 💾 Save Config — this writes ai.js, .env and bot-config.json into your bot folder automatically.
3
Click ▶ Start Bot
The server starts the bot process. A QR code appears right here in this page.
4
Scan with WhatsApp
WhatsApp → Settings → Linked Devices → Link a Device → scan the QR above.
📲Point camera at QR above
5
Bot is live 🎉
Anyone messaging the linked number gets automated replies. Appointments book directly into DentCare Pro!
